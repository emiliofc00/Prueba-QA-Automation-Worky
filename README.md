Prueba-QA-Automation-Worky

Test para la prueba solicitada Prueba QA Automation Worky

Pasos

1.- Contar con las dependecias c# , Selenium, Nunit, Allure y dotnet 10 

2.- Abrir una terminal en la carpeta del Proyecto  

3.- Correr el comando "dotnet build formFillTest.slnx

4.- Correr el comando "dotnet test formFillTest.slnx

Para generar el reporte de allure

Pasos

1.- Vaya a formFillTest\bin\Debug\net10.0

2.- Correr el comando "allure open"
